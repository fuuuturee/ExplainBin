ExplainBin @VERSION@ is a self-contained installer. Download the single
`ExplainBin-@VERSION@-Setup.exe` file and run it; no separate Qt runtime or
Visual C++ download is required.

- Windows 10/11, x64
- Per-user install, no administrator rights required
- Includes the GUI and the `explainbin-cli.exe` command-line analyzer
- Clean dark and light interface with optional interface animations
- Static analysis only: analyzed files are never executed or loaded
